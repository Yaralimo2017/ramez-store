# RAMEZ

موقع متجر RAMEZ للملابس والأحذية والإكسسوارات الرجالي والحريمي، بالعربي والإنجليزي.

- `index.html`: الموقع كله (التصميم والكود والبيانات) في ملف واحد.
- `images/`: اللوجو، ومكان صور المنتجات.

## تشغيله على جهازك
افتح `index.html` في المتصفح.

## إضافة صور المنتجات
حط الصورة في `images/` (مثلًا `images/m1.jpg`)، وبعدين اكتبها في `const IMG={}` داخل `index.html`:

```js
const IMG={m1:'images/m1.jpg', w6:'images/w6.jpg'};
```

أرقام المنتجات (`m1`…`m9` رجالي، `w1`…`w9` حريمي) موجودة في قائمة `const P` في نفس الملف.

## ملاحظة
ده نسخة عرض: زرار إتمام الطلب وفورم حجز الموعد مش بيبعتوا بيانات لأي جهة لحد ما يتربطوا ببوابة دفع وسيرفر.
